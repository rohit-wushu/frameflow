# Template catalog

Generated by `pnpm templates:catalog` from packages/templates. Do not edit by hand.

Each scene picks one template and fills its `content` with the fields below.
The first scene must be a hook template; the last must be `logo_reveal` or `cta`;
the same template may not appear twice in a row.

## hero_text

- **Category:** hook (can open the video)
- **Duration:** 2-6 s
- **What it shows:** Big bold headline with an optional eyebrow label above and one line of subtext below. The headline words rise in on the narrator's words when the voiceover says them; the highlight word turns the brand color with an underline as it is spoken.
- **When to use:** The opening hook, or any bold statement. Keep the headline short and punchy, and say it (or most of it) in the voiceover so the words land with the voice.

| Field | Type | Required | Limits | Notes |
|---|---|---|---|---|
| `eyebrow` | string | no | 1-28 chars | small label above the headline, e.g. the brand or a category |
| `headline` | string | yes | 3-60 chars | the big line, 2-8 words |
| `highlight` | string | no | 1-20 chars | one word of the headline to color with the brand color |
| `subtext` | string | no | 1-110 chars | one supporting sentence |

## kinetic_words

- **Category:** hook (can open the video)
- **Duration:** 2-7 s
- **What it shows:** Kinetic typography: one short statement in very big type. Each word pops in exactly when the narrator says it; the emphasis word gets a brand-color marker swiping behind it.
- **When to use:** A punchy opener or a bold line between sections (2-14 words). The voiceover must say the text word for word, so every word lands on the voice.

| Field | Type | Required | Limits | Notes |
|---|---|---|---|---|
| `text` | string | yes | 3-90 chars | the statement, said word for word in the voiceover |
| `emphasis` | string | no | 1-20 chars | one word of the text to mark with the brand color |

## problem_list

- **Category:** content
- **Duration:** 3-8 s
- **What it shows:** A title and 2-4 pain points. Each point slides in when the narrator names it. Style "cross": once all are shown, a brand-color line strikes through each one and they fade back, as if solved. Style "stack": the points land as tilted cards piling up.
- **When to use:** Name the problem before the solution (2-4 short pain points). Say each point (or its first word) in the voiceover, in order. Use "cross" when the next scene is the fix.

| Field | Type | Required | Limits | Notes |
|---|---|---|---|---|
| `title` | string | yes | 2-48 chars | the heading, e.g. 'Making videos today' |
| `items` | array of string | yes | 2-4 items | the pain points, 2-6 words each |
| `style` | string | no | default "cross" | "cross" strikes them out at the end; "stack" piles them up |

## feature_grid

- **Category:** content
- **Duration:** 3-8 s
- **What it shows:** A title and 2-4 feature cards, each with a Tabler icon, a short title and an optional line of text. Cards pop in one by one as the narrator names them, and their icons draw themselves.
- **When to use:** Show 2-4 features or benefits together. Say each card's title in the voiceover, in order, so every card lands on its word.

| Field | Type | Required | Limits | Notes |
|---|---|---|---|---|
| `title` | string | yes | 2-44 chars | the heading above the cards |
| `items` | array of object | yes | 2-4 items |  |
| `items[].icon` | string | yes |  | Tabler outline icon name, e.g. microphone, sparkles, chart-bar |
| `items[].title` | string | yes | 2-24 chars |  |
| `items[].text` | string | no | 2-64 chars |  |

## feature_spotlight

- **Category:** content
- **Duration:** 3-7 s
- **What it shows:** One feature, up close: a big title, one short line, and a visual. The visual is an image (a screenshot, by name) or a large Tabler icon in a glowing circle that draws itself. Landscape puts the visual on the right; portrait and square stack it on top.
- **When to use:** Give one important feature its own moment. Say the title in the voiceover. Use an image when one shows the feature, otherwise an icon.

| Field | Type | Required | Limits | Notes |
|---|---|---|---|---|
| `eyebrow` | string | no | 1-28 chars | small label above the title, e.g. 'New' |
| `title` | string | yes | 2-44 chars | the feature, 2-6 words |
| `text` | string | yes | 2-120 chars | one sentence on what it does for the viewer |
| `icon` | string | no |  | Tabler outline icon, shown when there is no image |
| `image` | string | no | 1-∞ chars | name of an available image (e.g. website); replaces the icon |

## stat_counter

- **Category:** content
- **Duration:** 2.5-6 s
- **What it shows:** One big number that counts up like an odometer, with an optional prefix/suffix in the brand color, a label under it and an optional small context line. The count starts when the narrator says the number.
- **When to use:** A single strong metric (users, hours saved, growth). Write the number in digits in the voiceover (e.g. '10,000 teams') so the count starts on it.

| Field | Type | Required | Limits | Notes |
|---|---|---|---|---|
| `value` | number | yes | 0 to 999999999 | the number to count up to |
| `decimals` | integer | no | 0 to 2, default 0 |  |
| `prefix` | string | no | 1-3 chars | shown before the number, e.g. "$" or "+" |
| `suffix` | string | no | 1-8 chars | shown after the number, e.g. "%", "x", "k" |
| `label` | string | yes | 2-56 chars | what the number means |
| `context` | string | no | 2-48 chars | small print, e.g. a source or time frame |

## device_mockup

- **Category:** content
- **Duration:** 3-8 s
- **What it shows:** A screenshot inside a browser window, laptop or phone frame. The device tilts up into view, then the screen slowly scrolls (tall images) or zooms. Optional title and subtitle beside it (landscape) or above it (portrait, square).
- **When to use:** Show the real product or website. Needs an image by name: the desktop screenshot in "browser" or "laptop", the phone screenshot in "phone" (best for 9:16). Say the title in the voiceover.

| Field | Type | Required | Limits | Notes |
|---|---|---|---|---|
| `image` | string | yes | 1-∞ chars | name of an available image, e.g. website or website-mobile |
| `device` | string | no | default "browser" | the frame around the screenshot |
| `title` | string | no | 2-40 chars | short line next to the device |
| `subtitle` | string | no | 2-80 chars |  |

## screenshot_zoom

- **Category:** content
- **Duration:** 3.5-8 s
- **What it shows:** A full screenshot, then the camera zooms into one named area of it (e.g. the main button or the headline). The rest dims, a brand-color ring frames the area, and an optional callout label points at it.
- **When to use:** Point at one specific thing on the website or product. Needs an image by name and a focus: one of its zoom regions (listed with the image), or "center" / "top". The zoom happens about a second in, so mention the thing then.

| Field | Type | Required | Limits | Notes |
|---|---|---|---|---|
| `image` | string | yes | 1-∞ chars | name of an available image, e.g. website |
| `focus` | string | no | 1-∞ chars, default "center" | a zoom region of the image (e.g. button, headline), or "center" / "top" |
| `title` | string | no | 2-40 chars | short line above the screenshot |
| `callout` | string | no | 2-36 chars | label pointing at the zoomed area |

## comparison

- **Category:** content
- **Duration:** 4-9 s
- **What it shows:** Two columns: the old way (left, muted, with crosses) and the better way (right, in the brand color, with checks). The left column appears first; each right-hand point lands when the narrator says it, and the right column lights up at the end. Portrait stacks the columns.
- **When to use:** Before vs after, or the usual way vs this product (2-4 points a side). The voiceover should mainly say the right-hand points, in order.

| Field | Type | Required | Limits | Notes |
|---|---|---|---|---|
| `title` | string | no | 2-44 chars | a heading above both columns |
| `leftLabel` | string | yes | 2-24 chars | the old way, e.g. 'Before' or 'Agencies' |
| `left` | array of string | yes | 2-4 items | its downsides, 2-5 words each |
| `rightLabel` | string | yes | 2-24 chars | the better way, e.g. 'With Frameflow' |
| `right` | array of string | yes | 2-4 items | its upsides, 2-5 words each, said in the voiceover |

## testimonial

- **Category:** content
- **Duration:** 3-9 s
- **What it shows:** A customer quote in large type with a brand-color quote mark. The words appear as the narrator reads them, then the person's initials, name and role slide in underneath.
- **When to use:** Only for a real quote that appears in the brief or on the website, word for word, with the person's real name. Never invent a quote or a person. Read the quote in the voiceover.

| Field | Type | Required | Limits | Notes |
|---|---|---|---|---|
| `quote` | string | yes | 10-180 chars | the exact quote, without quotation marks |
| `name` | string | yes | 2-40 chars | who said it (a real person from the source) |
| `role` | string | no | 2-60 chars | their title and company, e.g. 'Head of Growth, Acme' |

## cta

- **Category:** end (can close the video)
- **Duration:** 3-6 s
- **What it shows:** Call to action: a headline, an optional subline, a button that an animated cursor clicks on the accent (with a click sound), and an optional URL under it.
- **When to use:** The ask at the end: sign up, try it free, book a demo. Use it as the last scene, or right before logo_reveal.

| Field | Type | Required | Limits | Notes |
|---|---|---|---|---|
| `headline` | string | yes | 2-40 chars | the ask, e.g. 'Make your first video' |
| `subline` | string | no | 2-80 chars |  |
| `buttonText` | string | yes | 2-22 chars |  |
| `url` | string | no | 3-40 chars | shown under the button, e.g. example.com/start |

## logo_reveal

- **Category:** end (can close the video)
- **Duration:** 2.5-5 s
- **What it shows:** The brand logo (or the brand name as a wordmark when there is no logo) bursts in on a hit, followed by an optional tagline.
- **When to use:** Always the ending. Keep the voiceover to the brand name and/or the tagline, or leave it empty.

| Field | Type | Required | Limits | Notes |
|---|---|---|---|---|
| `tagline` | string | no | 2-56 chars | short line under the logo |
